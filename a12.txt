Q: Why does the addStudent function use realloc() instead of relying on a standard
array with a fixed size?
A: Using realloc() allows the database to grow dynamically as new students are added. This
prevents hardcoded memory limits (avoiding array overflow) and optimizes memory usage by only
allocating space when it is strictly needed.
Q: How does the program know to dynamically allocate more memory when a new
entry is added?
A: The program compares the current number of students ( count ) with the total available slots
( capacity ). When count == capacity , it triggers realloc() to increase the capacity by 1 and
reallocate the memory block.
Q: Before the Binary Search can successfully find ID 101, what logical step must the
program execute first, and why?
A: The program must call sortByID() to sort the array in ascending order. Binary search works
by continually dividing the search space in half, which mathematically requires the data to be in a
strictly sorted sequence.
Q: Explain the swapping logic used inside the sortByID function.
A: It uses a Bubble Sort approach, comparing adjacent elements ( students[j] and
students[j+1] ). If the current ID is greater than the next ID, they are swapped using the built-in
swap() function to bubble the largest values to the end.
Q: What occurs logically if realloc() fails to assign new memory?
A: If memory allocation fails, realloc() returns a NULL pointer. The program checks for this
( if (!students) ), prints a "Memory allocation failed!" error message, and gracefully terminates
the execution using exit(1) .

Assignment No. 5 – Binary Search Tree and Its Operations
1. What is a Tree?
A non-linear data structure made of nodes connected by edges.
2. What is a Binary Search Tree (BST)?
A binary tree where smaller keys go to the left and larger keys go to the right of a node.
3. What is the Root Node?
The topmost node of the tree.
4. What is a Leaf Node?
A node that has no children.
5. What is Inorder Traversal?
Visiting Left subtree, Root, then Right subtree; in a BST it gives keys in sorted order.
6. What is Preorder Traversal?
Visiting Root, Left subtree, then Right subtree.
7. What is Postorder Traversal?
Visiting Left subtree, Right subtree, then Root.
8. How does deletion work when a BST node has two children?
Replace its key with its inorder successor (the minimum in the right subtree), then delete that successor.
9. What is the depth/height calculation used in this program?
For an empty node it returns 0; otherwise it returns 1 plus the maximum depth of its left and right subtrees.
10. What is Level Order Traversal and which data structure does the program use?
It visits nodes level by level and uses a queue (deque in the Python program).
Q: How does the _insert logic identify and handle duplicate entries (like '70' in the
output)?
A: As it traverses down the tree checking key < node.key and key > node.key , if it finds a

Q: When deleting a node with two children, why does the logic search for the minimum
node in the right subtree?
A: To maintain the strict properties of a BST, the deleted node must be replaced by its Inorder
Successor (the smallest value that is still strictly larger than the node's left subtree). The minimum

Q: Explain the recursive logic used in the depth() function.

A: It initializes a queue with the root node. In a loop, it processes the queue by determining the
current level_size , popping that many nodes, recording their keys, and pushing their non-null
left and right children into the queue for the next iteration.

result of the original node.right to the new node's left child, and node.left to the right
child, physically flipping the tree



Assignment No. 6 – College Campus Graph and Minimum Spanning Tree
1. What is a Graph?
A non-linear structure consisting of vertices (nodes) and edges (connections).

A two-dimensional array in which a cell records the edge or weight between two vertices.

A representation that stores, for each vertex, the vertices connected to it.
6. What is a Minimum Spanning Tree (MST)?
A set of edges connecting all vertices of a connected, weighted, undirected graph with minimum total weight and no

7. How many edges does an MST have for V vertices?
V − 1 edges.

8. What is Kruskal's Algorithm?
It sorts edges by weight and adds the next lightest edge if it does not create a cycle.
9. What is Prim's Algorithm?
It starts from a vertex and repeatedly adds the cheapest edge connecting the current tree to a vertex outside it.
10. What is the main difference between Prim's and Kruskal's algorithms?
Prim grows one tree from a starting vertex; Kruskal selects globally sorted edges while joining separate components.
Q: How does the Adjacency Matrix logic represent paths between departments?
A: A value of 0 at matrix[u][v] indicates there is no direct path. Any non-zero integer
represents a valid path, where the integer itself signifies the distance (weight) between department
u and department v .
Q: In Kruskal's algorithm, what role do find and union play in preventing cycles?
A: find traces nodes back to their root parents. If the edge being evaluated connects two nodes
with the exact same root ( find(u) == find(v) ), it means a cycle would form. union merges two
disjoint sets into one when a valid, non-cyclic edge is added.
Q: Why must edges be sorted by weight before executing Kruskal's algorithm?
A: Kruskal's algorithm is a greedy approach. It mandates evaluating edges from the absolute
shortest to the longest to guarantee that the final spanning tree has the minimum possible total
weight.
Q: Explain how Prim's algorithm uses the key array and mst_set .
A: key tracks the minimum distance required to connect each node to the growing MST.
mst_set is a boolean array tracking which nodes are already secured in the MST. At each step, it
greedily selects the node not in mst_set that has the absolute smallest key value.
Q: Will Kruskal's and Prim's algorithms always yield the exact same Total Distance?
A: Yes. While they may select slightly different edges if multiple edges have identical weights, the
mathematical property of Minimum Spanning Trees guarantees that the final optimized Total
Distance will always be identical


Assignment No. 7 – Heap Sort
1. What is a Heap?
A complete binary tree that follows the heap property.
2. What is a Max Heap?
A heap in which every parent is greater than or equal to its children.
3. What is a Min Heap?
A heap in which every parent is less than or equal to its children.
4. What is Heap Sort?
A comparison-based sorting algorithm that uses a heap to order elements.
5. Which heap does this assignment use?
A Max Heap, to sort the array in ascending order.
6. What is heapify?
The operation that restores the heap property in a subtree.
7. Why is the largest element swapped with the last element in this program?
The root of a Max Heap is the largest; moving it to the end places it in its final sorted position.
8. What are the left and right child indices in the array representation?
For index i: left child = 2i + 1; right child = 2i + 2.
9. What is the time complexity of Heap Sort?
O(n log n) in best, average and worst cases.
10. Is Heap Sort stable?
No. Equal elements are not guaranteed to keep their original relative order.
Q: How are the logical indices for a node's left and right children calculated?
A: When a complete binary tree is flattened into a 0-indexed array, for any node at index i , its left
child is always found at index 2*i + 1 , and its right child is at 2*i + 2 .
Q: Why is the largest number placed at the root of the constructed Max-Heap?
A: A Max-Heap enforces the rule that every parent node must be greater than or equal to its
children. By repeatedly applying heapify from the bottom up, the absolute maximum value
bubbles up to index 0 (the root).

Q: Explain the swapping logic during the extraction phase of Heap Sort.
A: Since the root (index 0) is guaranteed to be the largest unsorted element, it is swapped with the
element at the very end of the active array. The active array size is then reduced by 1, permanently
locking that maximum element into its correct sorted position.
Q: How does heapify ensure the subtree remains valid after a swap?
A: When a small element is swapped to the root, it violates the heap property. heapify compares
it to its two children, identifies the largest, swaps them if necessary, and then recursively calls
heapify on the affected child branch to push the small element down.
Q: Why does the initial Max-Heap construction loop start from n//2 - 1 ?
A: All elements from index n//2 to n-1 are leaf nodes, meaning they have no children and are
already trivial heaps. The algorithm optimizes by starting at the last non-leaf node and working
backward to the root

Assignment No. 9 – Fractional Knapsack
1. What is the Knapsack Problem?
Selecting items with weights and profits to maximize profit without exceeding a capacity.
2. What is Fractional Knapsack?
A knapsack problem where an item may be taken completely or partially.
3. What is a Greedy Algorithm?
An approach that repeatedly makes the best local choice according to a chosen rule.
4. Which greedy rule is used in this assignment?
Choose parcels in descending order of profit-to-weight ratio.
5. How is the profit-to-weight ratio calculated?
Profit divided by weight.
6. Why are items sorted by this ratio?
To get the greatest profit per unit of capacity first.
7. Can an item be divided in Fractional Knapsack?
Yes. The algorithm can take a fraction of the final parcel.
8. What is the difference between Fractional and 0/1 Knapsack?
Fractional allows partial items; 0/1 requires taking an item entirely or not taking it.
9. How is the profit from a partial item calculated?
Fraction taken × item's full profit, where fraction = remaining capacity ÷ item weight.
10. What is the time complexity of this implementation?
O(n log n), mainly because it sorts the items by ratio.
Q: How does calculating the profit-to-weight ratio help maximize total profit?
A: The greedy strategy dictates selecting items that offer the most value per unit of capacity. The
profit-to-weight ratio identifies these high-value dense items, ensuring the limited truck space is
filled as profitably as possible.
Q: Why does the program sort the ratio list in reverse (descending) order?
A: Sorting descending puts the parcels with the absolute highest profit-to-weight ratios at the front
of the list (index 0), allowing the greedy loop to effortlessly evaluate and select the best items first.
Q: How is the percentage calculated when a parcel exceeds remaining capacity (e.g.,
66.67%)?
A: When the full parcel won't fit ( w > capacity ), it calculates the fraction by dividing the
remaining truck capacity by the item's total weight w . It then multiplies the total profit of that
item by this exact decimal fraction.
Q: What is the logical exit condition for the loop if the truck fills up early?
A: The loop includes a guard clause: if capacity <= 0: break . Once the capacity drops to zero,
the truck is entirely full, and iterating further is useless, so it terminates the loop early.
Q: Could this ratio-based logic work if the company was strictly forbidden from

A: No. If items cannot be split, it becomes the "0/1 Knapsack Problem." The greedy ratio approach
fails here because leaving empty space in the truck might yield less profit than picking a slightly less
dense, but better-fitting, combination of whole items. Dynamic Programming is required instead
